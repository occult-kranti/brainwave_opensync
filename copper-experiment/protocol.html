SPHERE / VELOCITY

A specified surface component.

Laser vibrometry reports projected velocity in m/s. Keep the surface fiducial, angle and band calibrated at A and B.

DRIVE / FORCE

Calibrate the input.

Velocity/force mobility has units (m/s)/N. Drive voltage alone gives a different transfer function and cannot be labeled force.

TABLE / ACCELERATION

Keep the observable distinct.

Acceleration PSD has units (m/s²)²/Hz. It is not the same quantity as displacement/force receptance in m/N.

OFFLINE / YOUR FILES STAY LOCAL

Analyze calibrated records.

The command-line tools estimate H1/coherence from stationary synchronized traces and compare user-supplied matched-mode fits across balanced blocks. They do not acquire hardware or fit natural poles.

python analysis/make_demo.py --output /tmp/copper-demo
python analysis/analyze.py trace /tmp/copper-demo/synthetic-trace.csv \
  --metadata /tmp/copper-demo/synthetic-trace.metadata.json \
  --f-min 100 --f-max 3000 --nperseg 512 \
  --output /tmp/copper-demo/trace-analysis.json
python analysis/analyze.py blocks /tmp/copper-demo/synthetic-blocks.csv \
  --metadata /tmp/copper-demo/synthetic-blocks.metadata.json \
  --output /tmp/copper-demo/block-analysis.json

Run from an extracted source archive with the pinned analysis dependencies installed. Choose fresh output paths. Both tools require a byte-bound metadata sidecar. Synthetic status comes from that sidecar; an optional --synthetic flag only checks it and cannot relabel data.

Browser exports are different input schemas. The synthetic waveform has arbitrary sensor units, and the mechanics CSV contains response magnitudes in m/N. Neither is a force/velocity trace admitted by the analyzer. Do not rename these columns to imply calibrated hardware channels.

For a real trace, first prepare and review a measurement-input-unverified sidecar. A declaration cannot authenticate calibration or physical origin.

python analysis/analyze.py metadata my-trace.csv --record-type trace \
  --data-kind measurement-input-unverified --output my-trace.metadata.json
python analysis/analyze.py trace my-trace.csv --metadata my-trace.metadata.json \
  --f-min 100 --f-max 3000 --nperseg 1024 --output my-trace.analysis.json
