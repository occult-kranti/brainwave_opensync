Six specialized model-agents, three adaptive research rounds, and one complete energy accounting question. This is a research and simulation workspace, not a physical free-energy demonstration. Author/project credit: Hruday N M / BUNZEEY. No human or historical-scientist participation is implied.

Source branch: `research/energy-observatory`. Live route: `https://occult-kranti.github.io/brainwave_opensync/devices/energy/`.

## Run

From `energy-observatory/`: `npm run check`, then `npm run serve`. The browser needs no third-party runtime libraries. Open `http://localhost:4180/`.

See `research/contract.json`, the per-round panel records, `research/advisor.md`, and each analysis script/receipt for model assumptions, provenance and executed checks. Sources record actual reading depth. Public program announcements and patents are evidence of their contents, not certificates of net energy production. Numerical agreement validates the selected implementation, not a physical apparatus.

The `versions/` directory preserves original source bytes for the earlier copper lab releases. `data/versions.json` binds them to pinned commits and records deployment-only adaptations. No complete third-party papers are redistributed. Code follows the repository MIT license; source publications retain their own rights.
