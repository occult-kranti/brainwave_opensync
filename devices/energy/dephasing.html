THE STATEMENT / ALL VALID STATES

How much work
can coherence unlock?

0 ≤ W(1) − W(d) ≤ ε |c| (1 − d)

H = diag(0, ε), ε > 0. The state is ρ = [[1−p, c], [c*, p]], with 0 ≤ p ≤ 1 and |c|² ≤ p(1−p). Dephasing sends c to dc for 0 ≤ d ≤ 1 and preserves p.

W(d) is the initial mean energy minus the lowest energy attainable by any single-qubit unitary. It assumes suitable phase access and an ideal cyclic control operation.

Complete proof ↗Frozen contract ↗

Three steps make the bound.

  1. Order the spectrum. Set z = 1−2p and Rd = √(z² + 4d²|c|²). The eigenvalues are (1±Rd)/2.
  2. Attain the minimum. Map the larger-eigenvalue state to the ground level and the smaller to the excited level. Then W(d) = ε(Rd−z)/2.
  3. Compare two lengths. The triangle inequality applied to (z, 2|c|) = (z, 2d|c|) + (0, 2|c|(1−d)) gives the upper bound. Monotonicity gives the lower bound.

At p = 0 or 1, positivity forces c = 0. At the maximally mixed state the eigenvalue radius vanishes; the argument uses the explicit zero branch. This is an analytic argument, not a proof-assistant certificate.
