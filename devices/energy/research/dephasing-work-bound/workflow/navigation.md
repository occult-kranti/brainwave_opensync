## Four support roles and the advisor

Source auditor: read closest primary theorem statements, preserve access date/reading depth/license and distinguish inherited from freshly read evidence. Identify novelty limits.
Physical reviewer: audit state domain, operations, phase reference, units and full energy meaning; distinguish supplied-state work from preparation/control/reset costs.
Knowledge integrator: keep historical planning immutable; add explicit execution status, proof/source links and typed graph edges; test deep links and interactive calculator under the deployment base.
Skeptic: freeze independent falsification criteria before seeing production. Test omitted endpoints, equality necessity, bad controls and wording inflation; retain objections until evidence closes them.
Advisor: choose the smallest task with explicit premises. Match six roles/two dedicated workers when requested. Freeze each later round only after reading all six earlier reports. Record decision, changed artifact and remaining issue; finish at the requested count. Separate skill validity, mathematical proof, numerical execution, remote source and live deployment evidence.

## Compact evidence receipt

Return a record such as `{claimId, inputRevision, sourceHashes, command, exitCode, observedResult, unresolvedLimit}`. Populate it from executed evidence. A fabricated example value is not a test result. Keep source reading depth and theorem acceptance separate from numeric pass status.

## Preserve numeric inputs and evidence coverage

Audit UI parameter conversions before invoking a validated scientific kernel. A positive normalized control may underflow to zero during conversion; reject or visibly identify that change instead of treating its equality flags as properties of the requested state. Give stored energy the same range treatment as work outputs.

Require an explicit minimum source set in a release manifest, including every admitted round report and executed checker. A loop over supplied hashes can pass vacuously when the manifest is empty. Test the missing-entry gate with an otherwise admitted record so an earlier generic status guard does not conceal the defect.
