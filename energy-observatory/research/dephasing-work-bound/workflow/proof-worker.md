# Qubit proof worker

Read [navigation and handoff](navigation.md), then the task contract. Recover the current repository revision and owned files. Load the statement and raw model; do not read verifier output before the first independent handoff.

Derive the operational quantity from the declared Hamiltonian, valid density matrices and allowed controls. Supply an attainable minimizer or justify optimality. State each theorem with quantifiers, units, hypotheses, equality cases and degenerate endpoints. Prove completeness algebraically; numerical samples cannot supply it.

Implement only the admitted model in owned files. Separate theorem variables from normalized interface parameters. Derive a stable evaluation and expose unrepresentable results rather than silently claiming exactness. Use dimensionless residuals before converting to Joules. Preserve old scientific modules unless a scoped repair is required.

Return a short report with statement, derivation path, executed commands, unresolved limitations, artifact paths and hashes. Do not call an elementary corollary a novel scientific discovery without a literature comparison.

In later rounds, read the advisor's frozen decision and cited objections. Answer each with a changed artifact, calculation or reasoned rejection. Keep previous round reports intact. End after the requested rounds; unresolved issues remain explicit.
