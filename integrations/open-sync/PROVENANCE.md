All upstream tracked source files, data, tests, manifests and scripts are retained. The application is built independently and deployed under `/brainwave_opensync/open-sync/`; the current laboratory remains at the project root, and the earlier release remains at `/v2/`.

Deployment adaptations: hash routing for static hosting; Vite base-aware previews and stimulus URLs; a link back to Connected projects; pinned dependency lockfile. These adapters do not alter the original DSP equations. Existing source claims retain the original collection's evidence grades and should be read as that archive's assessments.

The upstream source omits generated WAV files. Preset previews are regenerated by the preserved renderer. The 20 X10 stimuli are copied from the current repository only after SHA-256 and byte-count checks against the imported manifest (`node scripts/prepare-open-sync.mjs` from the repository root). Missing or changed files stop the build.

Run from this directory:

```sh
npm ci --no-audit --no-fund
node scripts/render-previews.mjs
npm test
VITE_BASE=/brainwave_opensync/open-sync/ npm run build
```

Run `node scripts/prepare-open-sync.mjs` from the parent repository root before testing/building the full deployed suite. The parent build, linter and test suite are scoped separately; this suite keeps its own tests and dependencies.
