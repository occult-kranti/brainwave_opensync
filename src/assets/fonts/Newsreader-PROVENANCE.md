# Newsreader font

Upstream: https://github.com/google/fonts/tree/main/ofl/newsreader

Source: Newsreader[opsz,wght].ttf, fetched 2026-10-29. SIL Open Font License retained in Newsreader-OFL.txt. FontTools subset preserves Latin, general punctuation, euro and trademark glyphs in a self-hosted WOFF variable font. Used for editorial headings; Inter remains the body/control face. No paid font service or runtime request is required.
